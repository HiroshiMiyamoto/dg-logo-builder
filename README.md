# Demand Gen ロゴアセット ビルダー

**公開URL: https://hiroshimiyamoto.github.io/dg-logo-builder/**

Google 広告 デマンドジェネレーションキャンペーンの「シングルイメージ広告」で必須となる
**ロゴ**アセットを、規定の 1:1 / 1200×1200px に整えて書き出すツールです。

ビルド・サーバー・API キーは不要です。アップロードした画像はブラウザ内でのみ処理され、
外部に送信されません。

## 使い方

1. ロゴの元画像をドロップまたは選択する
2. 背景（白・指定色・元画像のまま・透過）とセーフマージンを決める
3. 「PNG をダウンロード」を押す

アップロードした画像の実コンテンツ部分を自動検出し、1200×1200px の正方形キャンバス中央へ、
指定したセーフマージンで配置します。元画像にもともと入っている余白は除外して計算するため、
余白が二重になりません。

実寸・アスペクト比・透過の有無・既存余白の割合・主要色を自動で表示し、
短辺が 144px 未満（最小要件割れ）や 600px 未満（拡大で劣化のおそれ）の場合は警告します。

## 生成AIは使いません

元画像をそのまま配置・リサイズしているだけなので、ロゴの形・字形・色は一切変わりません。
ロゴは商標であり、生成AIで描き直すと字形・線の太さ・色が必ず微妙に変化して、
広告審査とブランド管理の両面で問題になります。本ツールはその経路を取りません。

## ロゴの仕様（2026-10 時点）

| 項目 | 値 |
|---|---|
| アスペクト比 | 1:1（必須） |
| 推奨サイズ | 1200 × 1200 px |
| 最小サイズ | 144 × 144 px |
| 形式 | JPG / PNG / 静止 GIF |
| 最大ファイルサイズ | 5,120 KB |

出典: [デマンド ジェネレーション キャンペーンの仕様とフォーマットの要件](https://support.google.com/google-ads/answer/17091672?hl=ja)

仕様は変更されることがあります。入稿前に最新のヘルプを確認してください。

## ローカルでの実行

`index.html` をブラウザで開くだけです。依存関係はありません。

## デプロイ

GitHub Pages の「Deploy from a branch」で `main` ブランチの `/ (root)` を配信しています。
`main` へ push すれば数十秒で反映されます。
