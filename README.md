# Demand Gen ロゴアセット ビルダー

**公開URL: https://hiroshimiyamoto.github.io/dg-logo-builder/**

Google 広告 デマンドジェネレーションキャンペーンの「シングルイメージ広告」で必須となる
**ロゴ**アセットを用意するための、単一 HTML のツールです。

ビルド・サーバー・API キーは不要です。アップロードした画像はブラウザ内でのみ処理され、
外部に送信されません。

## できること

1. **規定サイズ PNG の書き出し** — アップロードした画像の実コンテンツ部分を自動検出し、
   1200×1200px の正方形キャンバス中央に、指定したセーフマージンで配置して PNG を書き出します。
   生成 AI を経由しないため、ロゴの形・字形・色が一切変わりません。通常はこれで入稿できます。
2. **ChatGPT Images 用プロンプトの生成** — 背景の作り込みなど加工が必要な場合のための
   プロンプトを日本語・英語で出力します。元画像から抽出した実寸・比率・透過の有無・主要色を
   自動で埋め込みます。

## ロゴの仕様（2026-10 時点）

| 項目 | 値 |
|---|---|
| アスペクト比 | 1:1（必須） |
| 推奨サイズ | 1200 × 1200 px |
| 最小サイズ | 144 × 144 px |
| 形式 | JPG / PNG / 静止 GIF |
| 最大ファイルサイズ | 5,120 KB |

出典: [デマンド ジェネレーション キャンペーンの仕様とフォーマットの要件](https://support.google.com/google-ads/answer/17091672?hl=ja)

仕様は変更されることがあります。入稿前に最新のヘルプを確認してください。

## 設計上の注意

ロゴは商標です。生成 AI に「ロゴを描かせる」と、字形・線の太さ・色が必ず微妙に変化し、
広告審査とブランド管理の両面で問題になります。そのため本ツールのプロンプトは
既定で「描き直さず、配置と余白だけを整える」指示になっています。

また ChatGPT Images（gpt-image-1）の正方形出力は **1024×1024px が上限**で、
1200×1200px を直接出力できません。プロンプトには生成後にリサイズする手順を含めています。

## ローカルでの実行

`index.html` をブラウザで開くだけです。依存関係はありません。

## デプロイ

GitHub Pages の「Deploy from a branch」で `main` ブランチの `/ (root)` を配信しています。
`main` へ push すれば数十秒で反映されます。
