2. 設定

#FFFFFF

透過PNGは配信面によって白・黒どちらの背景にも載るため、ロゴが見えなくなる事故があります。迷ったら白を選んでください。

12%

ロゴの実コンテンツ部分を基準に、上下左右へ均等に余白を取ります。10〜15% が無難です。

ロゴは商標です。形・字形・色が変わると審査とブランド管理の両方で問題になるため、既定では「描き直さない」指示になります。

4. ChatGPT Images 用プロンプト

元画像をアップロードし、設定を入力するとプロンプトが生成されます。
コピーしました
使い方 ChatGPT のチャットに元のロゴ画像を添付した上で、このプロンプトを貼り付けてください。画像を添付せずに実行すると、ロゴが一から創作されてしまいます。

5. 入稿までの手順

  1. 上の 「PNG をダウンロード」 で足りるなら、それが最も確実です。形・色が一切変わらないため、商標面のリスクがありません。
  2. 背景の質感づくりなど加工が必要な場合のみ、プロンプトを ChatGPT Images で実行します。出力は 1024×1024 が上限のため、必ず 1200×1200 にリサイズしてから入稿してください。
  3. 生成結果は 元のロゴと重ねて確認します。字形・線の太さ・色が1pxでもずれていたら不採用にしてください。
  4. 最終ファイルは PNG / 1:1 / 1200×1200px / 5,120KB 以下であることを確認して入稿します。
仕様の出典：デマンド ジェネレーション キャンペーンの仕様とフォーマットの要件（Google 広告ヘルプ）。ロゴは 1:1 必須／推奨 1200×1200px（最小 144×144px）／JPG・PNG・静止GIF／最大 5,120KB。仕様は変更されることがあるため、入稿前に最新のヘルプをご確認ください。
